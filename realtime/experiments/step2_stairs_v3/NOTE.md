# 2단계: 공개 계단 데이터셋(Roboflow stairs v3)으로 전이학습

- 날짜: 2026-11-08
- 목적: 계단 클래스가 없는 사전학습 모델 대신, 계단이 라벨링된 데이터로 학습해서 계단을 찾게 한다
- 데이터: Roboflow Universe "stairs" v3 (CC BY 4.0)
  https://universe.roboflow.com/law-jqmvh/stairs-czu57/dataset/3
  1,952장 (train 1,608 / valid 230 / test 114), 폴리곤 세그멘테이션, 클래스 1개 `stair` (계단 전체를 하나로 라벨링)
- 시작 가중치: `yolo26n-seg.pt` (COCO 사전학습)
- 설정: epochs 50, imgsz 640, batch 16, seed 0, 그 외 ultralytics 8.4 기본값
- 환경: RTX 5070, torch 2.11 + CUDA 12.8
- 실행: `realtime/train.py --data realtime/datasets/stairs_v3.yaml --name step2_stairs_v3`
- 학습 시간: 26분 (0.434시간), best epoch 35

## 결론

- 공개 데이터 test 분할에서는 mask mAP50 0.89로 잘 동작한다.
- 팀 사진에서도 밝은 사진은 87% 탐지하지만, **매우 어두운 사진(밝기 30 미만)은 39%로 떨어지고 마스크도 절반 크기**다.
  같은 계단 쌍에서도 밝은 쪽만 찾는 경우가 16쌍으로 압도적이다.
- 어두운 사진에서 찾더라도 계단 실루엣의 일부만 잡는 경우가 있다 (seo06).
- 밝기 0~5 수준의 사진은 원본에 정보가 거의 없다. 전처리로도 복원이 어려울 수 있다.
